# 📸 VC_CENIMATIC – Photography & Cinematic Studio

**Capturing Moments. Creating Memories.**

VC_CENIMATIC is a modern and professional photography and cinematic studio website designed to showcase creative services, display photography work, and allow customers to send booking enquiries online.

The website features a premium **Black & Gold** design with a responsive layout and interactive booking functionality.

## 🌟 Project Overview

VC_CENIMATIC provides a digital platform for photography, videography, cinematic shoots, and graphic design services.

Whether it's a wedding, baby shoot, birthday, personal photoshoot, or creative project, VC_CENIMATIC helps customers explore services and connect with the studio.

**2. Open the project folder**

You can also use the Live Server extension in Visual Studio Code.

## 📩 Booking System

Customers can submit their booking enquiries through the website.

The booking form collects:

- Full Name
- WhatsApp Number
- Email Address
- Required Photography Service
- Preferred Date
- Shoot Location
- Additional Requirements

**WhatsApp Booking:** Opens WhatsApp with a pre-filled booking message.

**Email Booking:** Opens the user's default email application with booking details.

*Note: The current booking system uses WhatsApp links and email client integration. It does not store bookings in a database or automatically send emails through a backend.*
